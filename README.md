*Sara API*

API para automação do WhatsApp, semelhante à Evolution API, com interface de gerenciamento, autenticação, envio de mídia, integração com Typebot e n8n, e automação avançada.

*Pré-requisitos*
- VPS com Ubuntu 20.04/22.04
- Docker e Docker Compose
- MongoDB Atlas
- Cloudinary
- n8n (local ou Cloud, opcional)
- Ngrok ou Nginx
